# 買い物メモ 🛒🧊

家族で共有する、シンプルな買い物リストアプリです。
買い物リストはカテゴリー別に並び、**チェックした品物は自動で移動します**
（食材 → 🧊 冷蔵庫、日用品 → 🧴 家にあるもの）。
2人以上のスマホでリアルタイムに共有できます（ログイン不要）。

- ビルド不要の静的サイト（HTML / CSS / JavaScript）
- バックエンドは [Supabase](https://supabase.com/)
- PWA 対応（ホーム画面に追加すると全画面アプリになります）

---

## 1. Supabase の接続情報を貼る（最初に一度だけ）

`config.js` を開いて、2か所を書き換えてください。

```js
const SUPABASE_URL = "ここに Project URL を貼る";
const SUPABASE_ANON_KEY = "ここに anon public キーを貼る";
```

貼る値は Supabase の管理画面で確認できます：

1. Supabase のプロジェクトを開く
2. 左メニューの **Settings（歯車）→ API** を開く
3. **Project URL** を `SUPABASE_URL` に貼る
4. **Project API keys** の **anon public** を `SUPABASE_ANON_KEY` に貼る

> ℹ️ `anon` キーは「公開されても良い前提」のキーです。
> ただし家族用アプリなので、公開URL（次の手順で決まる GitHub Pages のアドレス）は
> 家族だけに教えて、むやみに広めないようにしてください。

### テーブルの前提

`items` テーブルが作成済みで、Realtime が有効・RLS が allow-all である前提です。

| 列名 | 型 | 説明 |
|------|-----|------|
| `id` | bigint | 主キー・自動採番 |
| `name` | text | 品物の名前 |
| `status` | text | `'buy'`（買い物リスト）/ `'fridge'`（冷蔵庫）/ `'home'`（家にあるもの・日用品）。既定は `'buy'` |
| `category` | text | カテゴリー（`vegetable` / `fruit` / `dairy` / `frozen` / `meat_fish` / `daily` / `other`）。既定は `'other'` |
| `created_at` | timestamptz | 追加日時 |

> ⚠️ **カテゴリー機能のために `category` 列の追加が必要です。**
> Supabase の左メニュー **SQL Editor** を開いて、次の1行を実行してください
> （すでに列がある場合は何も起きません）：
>
> ```sql
> alter table items add column if not exists category text default 'other';
> ```
>
> `status` は `'home'`（家にあるもの）も使うようになりました。`status` の型が
> テキストで allow-all のままなら、追加の設定は不要です。

## 2. GitHub Pages で公開する

このフォルダの中身を、そのまま GitHub のリポジトリに置いて公開します。

1. GitHub で新しいリポジトリを作る（例: `kaimono-memo`）。**Public** でOK。
2. このフォルダの全ファイルをアップロードする
   （`index.html` / `config.js` / `styles.css` / `app.js` /
   `manifest.json` / `sw.js` / `icons/` / `README.md`）。
   - Web からなら「Add file → Upload files」でドラッグ&ドロップ
   - コマンドが使えるなら以下でも可：
     ```bash
     git init
     git add .
     git commit -m "買い物メモ"
     git branch -M main
     git remote add origin https://github.com/ユーザー名/kaimono-memo.git
     git push -u origin main
     ```
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** の **Source** を **Deploy from a branch** にする
5. **Branch** を `main` ・フォルダを `/ (root)` にして **Save**
6. 少し待つと、ページ上部に公開URLが表示されます
   （例: `https://ユーザー名.github.io/kaimono-memo/`）
7. そのURLをスマホで開けば完成です 🎉

> 🔁 **ファイルを直したときは？**
> ファイルを更新して再アップロードしたあと、`sw.js` の中の
> `const CACHE_NAME = "kaimono-memo-v1";` の数字を `v2`, `v3`… と
> 上げると、各スマホで新しい内容にきちんと更新されます。

## 3. 母のスマホで「ホーム画面に追加」する

公開URLをスマホのブラウザで開いてから、下の手順でホーム画面にアイコンを置きます。
（普通のアプリのように、全画面で開けるようになります）

### 📱 iPhone（Safari）

1. **Safari** で公開URLを開く
2. 画面下の **共有ボタン**（□に↑の矢印）をタップ
3. メニューを下にスクロールして **「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ
5. ホーム画面に「買い物メモ」アイコンが出ます

> ※ iPhone では **Safari** で行ってください（Chrome だと出ないことがあります）。

### 🤖 Android（Chrome）

1. **Chrome** で公開URLを開く
2. 右上の **︙**（縦の3点メニュー）をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップ
4. **「追加 / インストール」** をタップ
5. ホーム画面に「買い物メモ」アイコンが出ます

## 使い方

### 買い物リスト（🛒）
- 入力欄に品物を入れて **エンター**（または「追加」）で追加
- **カテゴリーは品名から自動で選ばれます**（例：「にんじん」→野菜、「洗剤」→日用品）。
  ちがうときは、追加する前にドロップダウンで変えられます
- 追加した品物は、**カテゴリーごとに見出しが付いて並びます**（野菜・肉魚・日用品 など）
- 自動判定できない品物は「その他」（＝食材とみなして 🧊 冷蔵庫）になります
- 品物の左の **✓（チェック）** を押すと、**カテゴリーに応じて自動でうつります**
  - 食材（野菜・果物・乳製品・冷凍食品・肉魚・その他）→ 🧊 **冷蔵庫**
  - 日用品 → 🧴 **家にあるもの**
- **×** は削除（入力ミス用。どこにも移さず消えます）

### 冷蔵庫（🧊）
- もともと家にある食材は、冷蔵庫の入力欄から直接 **「追加」**
- 使い切ったら **×** で削除
- **「また買う」** で、買い物リストに戻せます

### 家にあるもの（🧴）
- 日用品のストック（洗剤・ティッシュなど）を入力欄から直接 **「追加」**
- 使い切ったら **×** で削除、**「また買う」** で買い物リストに戻せます

画面右上のランプが **緑** なら、リアルタイム同期はオンです。

## 困ったときは

- **品物が表示されない / エラーが出る**
  → `config.js` の URL・キーが正しいか確認してください。
- **相手の変更が反映されない**
  → Supabase で `items` テーブルの Realtime が有効か確認してください。
- **アイコンや見た目を変えたい**
  → 色は `styles.css` の上部（`:root` の変数）、
  アイコンは `icons/` の画像を差し替えてください。
